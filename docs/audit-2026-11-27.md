# Repository Audit Follow-Up (2026-11-27, Updated)

This document lists the remaining findings from the full-repository audit (559 tracked files) after the second cleanup pass. Items fixed in the first two passes have been removed; everything below requires design decisions, deeper root-cause investigation, golden re-recording, cross-module refactoring, or confirmation before unexporting public symbols.

---

## 1. Broken / Potential Bugs

### Pre-existing regressions on `HEAD`
1. **`emu/checks/check_perf.mjs` P10b fails on clean `HEAD` (`run/perf`, `run/perf-fault` in `golden.mjs check`)**
   - `default` executes `189,113,497` instructions while `OM_MACHINE=oneInsn=1` executes `189,116,834` (+3,337 instructions), causing `one-insn: stats differs from the default` (frames, lab time, hook log, stub hits, and output digest match).
   - Reproduced on clean `HEAD`; likely tied to enabling CPU 2 native by default on E143 (`8b4de49b`). Needs dedicated root-cause investigation.
2. **`emu/test/test_dispq.mjs` (`dispqSession`) fails on clean `HEAD` (`9/12`)**
   - Under `camapp 3` (`PLAY at the start's end`), `DISPLAY cmd 10` on task 165 runs immediately after `DISPLAY cmd 15` instead of task 168's kept `cmd 4`, `kept` is empty, and the `dispq-at-once` control does not stop at `S-DISPQ`.
   - Reproduced identically on clean `HEAD`; likely another timing shift from CPU 2 native being enabled by default on E143.

### Core & Cortex-M4
3. **`emu/src/core/m4/cpu.mjs:413-414` (`exceptionReturn`)**
   - Validates `toHandler && (psr & 0x1ff) === 0` / `!toHandler && (psr & 0x1ff) !== 0` *after* deactivating the exception and mutating registers/SP/xPSR. Needs ARMv7-M B1.5.8 verification before changing fault recovery order.
4. **`emu/src/core/m4/periph/i2c.mjs:83-91, 175` (`I2c`)**
   - `RELOAD` mode stalls permanently at `TCR`: writing `CR2` with new `NBYTES` does not clear `TCR`, update `this.cur.n`, or resume `this.next()`.
5. **`emu/src/core/m4/periph/rcc.mjs:72` (`Rcc.wr`) & `emu/src/core/m4/periph/rtc.mjs:72` (`Rtc.clockChanged`)**
   - Writes to `CSR` (`MSISRANGE`/`LSION`) and `CCIPR` (kernel clocks) do not notify `clockUsers`. `Rtc.clockChanged()` reschedules `secEv` but not `wuEv` (wake-up timer).

### Devices (`emu/src/dev/`)
6. **`emu/src/dev/timer.mjs:72, 82` (`romdWrite`)**
   - Passes negative `a - TIMER_BASE` into `this.error(...)`, wrapping the `ERR_RING` offset to `0xF1110000` (while stderr relies on `TIMER_BASE + off`). Changing the ring encoding affects debug-window consumers.
7. **`emu/src/dev/gio.mjs:38-47` (`GioKeyPins`)**
   - Registers status/enable regions and IRQs per pin without merging shared GIO groups (safe for E143's current 8 pins; latent overlap if two pins ever share a group).

### Firmware & Ports (`emu/src/fw/`)
8. **`emu/src/fw/expand.mjs:11, 50` (`expand`)**
   - `MAGIC` only checks 11 bytes (`'olycompress'`) and advances by `p + 1` rather than skipping past the decoded container. Needs verification across all supported firmware archives.
9. **`emu/src/fw/updater.mjs:28-34` (`ask`)**
   - Does not check `r.ok` on the HTTP response before calling `r.text()`; needs confirmation on how the vendor API responds for unknown models so `null`-return contracts aren't broken.
10. **`emu/src/fw/sections.mjs:148, 158` (`StagedLoadSchedule`)**
    - `readySection()` and `advanceTier()` do not normalize `this.mask |= ...` with `>>> 0`, which would diverge from unsigned `fullMask` if a 32nd section (bit 31) ever existed (currently 10 sections).

### HLE & Lab (`emu/src/lab/`)
11. **`emu/src/lab/a53isc.mjs:301-357` (`cgiStep`)**
    - Protocol errors that throw before MN-side rejection do not free `this.pool` handles or reset `this.cgi`; `test/test_a53isc.mjs:237` expects continuing the CGI request after a wrong-port error, so abort-vs-continue semantics need a design decision.
12. **`emu/src/lab/camapp.mjs:1543-1544` (`S-MOVRATE`)**
    - Advances `pc` by 2 bytes via `G` packet and then still calls `lab.passthrough(r)` (single-stepping `r.pc + 2` with breakpoints disabled). Only hits E118; needs E118 firmware verification.
13. **`emu/src/lab/osd.mjs:224-231` (`OsdLab.alloc`)**
    - Silently wraps back to `DATA` and overwrites earlier allocations once `DATA_END` is exceeded (no `free` mechanism; long sessions may rely on scratch wrap-around).
14. **`emu/src/lab/play.mjs:2301` (`switch_input`) & `emu/src/lab/player.mjs:193` (`tokenInt`)**
    - `modedial` checks `value >= 0 && value < positions` without `Number.isInteger(value)` (unlike `posswitch`); `tokenInt` splits on `:` and silently ignores trailing segments after the second colon.
15. **`emu/src/lab/menu.mjs:1458-1459` (`run_session`) & `emu/src/lab/menudata.mjs:36-38` (`Image.u16`/`u32`)**
    - `run_session` passes `pageId = null` to `validate_seed()` on non-ListMenu models; `Image.u16`/`u32` only validate the starting byte via `off(a)` and not the trailing 1–3 bytes.
16. **`emu/src/lab/cardfs.mjs:68-71, 183`, `emu/src/lab/acc.mjs:217`, `emu/src/lab/resources.mjs:55`**
    - Minor edge cases: `cardDevice.write` sets `card.dirty = true` before bounds checking and omits `lba < 0`; `FatWriter` does not validate active FAT index `(flags & 0xf) < this.nfats`; `Accelerometer.status()` calls `this.sample.slice()` before `bring_up()`; `lz4Block` `subarray` truncates instead of throwing `IndexError` on short literal tails.

### Debug, Host, Web & Refs
17. **`emu/src/debug/debugger.mjs:341` (`snapshotBytes`)**
    - Does not validate `this.snaps.has(h)` (unlike `restore`/`drop`), passing `undefined` to `m.snapshotBytes`.
18. **`emu/host/session.mjs:950-953` (`openSession` -> `close()`)**
    - `summary()` is still computed before `closePlayer()` (now refreshed via `note()` for stand-ins/audit, but post-close card/NVRAM flush state is not reflected; moving it after `closePlayer()` would require re-opening `fileCard` from disk).
19. **`emu/web/ui.mjs:480-495` (`sceneSync`)**
    - Omits `#sc-sh` (Shutter) because in `auto` mode `sc.exposure.shutter_s` is a continuous auto-computed value that doesn't match the `<select>` discrete options; needs a design decision (e.g. sync only in manual mode or expose manual shutter from `src/lab/scene.mjs`).
20. **`emu/refs/exif.mjs:15-20` & `emu/refs/jpeg.mjs:45`**
    - Do not validate JPEG segment length `>= 2` (can loop/rewind on corrupt files).

## 2. Inconsistencies

1. **`emu/bin/test-pure.mjs:66` & `emu/README.md:1665` vs `emu/bin/test.mjs`**
   - Docs/comments state `bin/test.mjs` runs all pure suites too, but 4 pure test suites are still missing from `bin/test.mjs`: `test_debug_cpu2.mjs`, `test_respatch.mjs`, `test_session_cli.mjs`, `test_web_args.mjs`.
2. **`emu/package.json:10-11`**
   - `npm run test:pure` and `npm run test:fast` are identical because `bin/test-pure.mjs` already skips `--facts` by default.
3. **`emu/src/fw/place.mjs:14` (`inDram`) vs `emu/src/fw/board.mjs:167-171, 275`**
   - `place.mjs` hardcodes 384 MiB DRAM (`0x60000000..0x78000000` / `0xa0000000..0xb8000000`), while `board.mjs` uses 512 MiB on E143/E146/E147/E129/E130/E132/E133.
4. **Duplicated helpers and code blocks (cross-module refactor candidates)**
   - Hex/byte helpers (`hex8`, `h8`, `u32`, `u16`, `pack32`, `cat`, `base64`) redefined across `src/core/`, `src/dev/`, `src/lab/`, `src/trace/`, `src/util/` (with `dev/bus.mjs` and `dev/engine.mjs` omitting `'0x'` in `hex8`).
   - `ERRORS` duplicated in `src/lab/osdfmt.mjs:9-11` and `src/lab/osd.mjs:48-50`.
   - `PLAY_SCRIPT` / `playWorkload` duplicated in `bin/playperf.mjs` and `web/runner.mjs`.
   - Chrome DevTools harness duplicated in `bin/webgate.mjs` and `bin/sitegate.mjs`.
   - `pool_map` duplicated in `checks/check_menu.mjs` and `checks/check_nav.mjs`; `patchFrames` duplicated in `bin/checktrace.mjs` and `checks/lib/childtrace.mjs`.
   - `usedLength` (`fw/xmap.mjs`, `fw/place.mjs`), `isHead` (`fw/identify.mjs`, `fw/respatch.mjs`), `plural` (`fw/patch.mjs`, `fw/respatch.mjs`).
5. **Device, Lab, Host & CLI conventions**
   - `dev/vsccompose2.mjs:257`: does not check `word >>> 29` for `E.PAL_FIELD` (unlike `vsccompose.mjs:322`).
   - `dev/intc.mjs:184-195`: clears `TEST_ONCE` only on bank 0, not bank `b2`.
   - `lab/player.mjs:525, 974`: `scene_used` and `scene_published` are not initialized in the constructor or reset across `open_session()`/`close_session()`.
   - `lab/display.mjs:223`: `ThRequest.replace(f)` shallow-copies array fields and omits `TH_FIELDS.includes(k)` validation.
   - `lab/rawframe.mjs:143-150`: throws plain `Error` instead of `FirmwareError`.
   - `lab/resnand.mjs:150, 168`: increments `this.reads` for container reads but not sound-area reads.
   - `host/firmware.mjs:84-88`: writes unpacked files in-place (`writeFileSync`) whereas `host/nvram.mjs` and `host/card.mjs` write atomically via `.tmp` + `renameSync` (needs PID/unique suffix to avoid multi-process races).
   - `host/session.mjs:250`: unrecognized-token error message omits `tilt:roll=R[,pitch=P]`.
   - `bin/checks.mjs` / manual arg parsers (`bench.mjs`, `sitegate.mjs`, `browsergate.mjs`, `webgate.mjs`, `snapgate.mjs`, `golden.mjs`): do not use `checks/lib/args.mjs` `parseArgs`, so unknown flags or missing option values may be silently ignored.
   - `bin/xwhere.mjs:14` vs `bin/xto.mjs:16`: differ on preload-row range checks and neither validates unknown models.
   - `checks/check_display.mjs:1025, 1110`: stdout still cites legacy filenames (`om1-vsc.c`, `check_nd128.py`, `check_isa.py`, `check_osd.py`), which are locked into `golden.json`.
   - `tools/a53-oracle/build-qemu.sh:34-38`: configures `--prefix="$PREFIX"` but builds `ninja qemu-system-aarch64` without `ninja install`.

## 3. Inefficiencies

1. **Hot-path allocations & serialization**
   - `emu/src/lab/scene.mjs:122-180, 224-225`: per-pixel nested `[[r,g,b], a]` arrays in `renderFrame` (requires refactoring all 7 pattern functions).
   - `emu/src/lab/player.mjs:973` & `emu/src/lab/play.mjs:3108`: `JSON.stringify` of full scene state every 50 ms idle slice and frame compose (needs a dirty counter/version in `scene.mjs`).
2. **Device / Lab / Tools algorithmic work**
   - `emu/src/dev/intc.mjs:107-123`: scans all 356 IRQs × 7 levels (+ second core) on every line toggle.
   - `emu/src/dev/engine.mjs:235-254`: reads destination rows twice when `KEY_MODE === 1`.
   - `emu/src/lab/kernel.mjs:144-146`: `NativeKernel.tasks()` calls `task_count()` in loop condition and repeats `tcb(tid)`/`entry(tid)`.
   - `emu/fwmap/discover.mjs:223, 236`: duplicate `kind === 'ptr-data' && !prologue && ...` condition.
   - `tools/a53-oracle/iscpeer.mjs:149-156, 320-321`: 1-byte `fs.readSync`/`writeSync` loops in `FileMem`.
   - `tools/m4-oracle/objcheck.mjs:40-45`: spawns one `objdump` process per run.
   - `tools/mn10300dis.sh:10`: uses `dd bs=1` (kept for macOS BSD `dd` compatibility).
