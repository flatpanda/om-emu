OM-Emu

The firmware of OM System and Olympus cameras, run in JavaScript in your browser: the OM-1's own menus, shooting screen and camera application on an emulated board, with the camera's buttons, dials and touch screen on the page.

Open the player

Your firmware stays in your browser

This site holds no camera firmware and has no server of its own: it is a set of static files. The player asks for the camera's firmware file (for the OM-1 v1.9, OLY_E_143_1900_0000_0000.BIN), reads it in a Web Worker in this browser, checks it against the release the emulator is written for, and keeps the unpacked parts in this browser's private storage (the Origin Private File System) so a later visit starts without it. Nothing is uploaded.

Getting the firmware

OM System's site does not offer the .BIN itself: its update tools fetch it from OM System's update service, and that service does not let a web page on another site fetch it. The player names the file each camera needs and shows a one-line command that downloads it from OM System's servers; choose or drop the file on the player afterwards. The download is subject to OM Digital Solutions' software licence, as with their own updaters.

Requirements

A recent desktop browser with module Workers and the Origin Private File System (tested in Chrome).
