# Repository Audit Follow-Up (2026-11-27)

This document lists the remaining findings from the full-repository audit (558 tracked files) that were **not** auto-fixed because they require design decisions, deeper root-cause investigation, golden re-recording, or confirmation that public exports/constants are no longer needed.

---

## 1. Broken / Potential Bugs

### Pre-existing regression on `HEAD`
1. **`emu/checks/check_perf.mjs` P10b fails on clean `HEAD` (`run/perf`, `run/perf-fault` in `golden.mjs check`)**
   - `default` executes `189,113,497` instructions while `OM_MACHINE=oneInsn=1` executes `189,116,834` (+3,337 instructions), causing `one-insn: stats differs from the default` (frames, lab time, hook log, stub hits, and output digest match).
   - Reproduced on clean `HEAD` (`07d51675`) before any audit edits; likely tied to enabling CPU 2 native by default on E143 (`8b4de49b`). Needs dedicated root-cause investigation.

### Core & Cortex-M4
2. **`emu/src/core/interp.mjs:234-243` (`resetInterp`)**
   - Does not reset module-level `TB_START`, `LOOKED_PC`, `LOOKED_N`, or `MMIO`.
3. **`emu/src/core/m4/sys.mjs:215-220` (`SystemBlock.write`)**
   - Narrow (8/16-bit) writes to word registers do read-modify-write via `peek32()`. On W1C/W1S registers (`CFSR`/`MMFSR`/`BFSR`/`UFSR`, `HFSR`, `DFSR`, NVIC `ISER`/`ICER`/`ISPR`/`ICPR`), copying `old` into unwritten bytes clears/sets sibling flags in unwritten bytes.
4. **`emu/src/core/m4/cpu.mjs:413-414` (`exceptionReturn`)**
   - Validates `toHandler && (psr & 0x1ff) === 0` / `!toHandler && (psr & 0x1ff) !== 0` *after* deactivating the exception and mutating registers/SP/xPSR.
5. **`emu/src/core/m4/periph/i2c.mjs:83-91, 175` (`I2c`)**
   - `RELOAD` mode stalls permanently at `TCR`: writing `CR2` with new `NBYTES` does not clear `TCR`, update `this.cur.n`, or resume `this.next()`. Also `start()`/`stopNow()` do not cancel a pending `this.ev` before overwriting it.
6. **`emu/src/core/m4/periph/gpio.mjs:83-108` (`Gpio`)**
   - `LCKR` lock mask is not applied to `AFRL`/`AFRH`; `keep(bitsPer)` uses `p % (32 / bitsPer)`, which would alias pins 8..15 onto 0..7 if called with `bitsPer = 4`.
7. **`emu/src/core/m4/periph/rcc.mjs:72` (`Rcc.wr`) & `emu/src/core/m4/periph/rtc.mjs:72` (`Rtc.clockChanged`)**
   - Writes to `CSR` (`MSISRANGE`/`LSION`) and `CCIPR` (kernel clocks) do not notify `clockUsers`. `Rtc.clockChanged()` reschedules `secEv` but not `wuEv` (wake-up timer).
8. **`emu/src/core/m4/periph/adc.mjs:61-76` & `emu/src/core/m4/periph/spi.mjs:78-80`**
   - Narrow writes to `ADC.CR`/`ADC.IER` clobber unwritten bytes; byte writes to `SPI.DR + 1..3` read `(v >>> 0) & 0xff` instead of shifting by lane offset.
9. **`emu/src/core/m4/periph/stm32l4.mjs:183` (`consoleText`)**
   - Uses `String.fromCharCode(...this.tx.LPUART1.slice(from))`, which can overflow the call stack for large outputs (> ~65 KiB).
10. **`emu/src/core/mem.mjs:135` (`setStrict`), `emu/src/core/cores.mjs:121-126` (`_polled`), `emu/src/core/m4/bus.mjs:82-95` (`rd`/`wr`)**
    - `setStrict` underflows `(hi - 1 + d) >>> 16` on an empty `[0, 0)` range; `_polled()` does not guard against `dbgRead()` returning `null`; `m4/bus.mjs` `rd`/`wr` assume unsigned `a` without `a >>>= 0`.
11. **`emu/src/util/bytes.mjs:107-111` (`parseFmt`) & `emu/src/util/equal.mjs:12-16` (`deepEqual`)**
    - `parseFmt` silently drops unrecognized format characters instead of throwing `StructError`; `deepEqual` on `Set`s of objects can false-positive when two elements in `a` match the same element in `b`.

### Devices (`emu/src/dev/`)
12. **`emu/src/dev/vsccompose.mjs:407-410` (`compose`, A21 `UNAPPLIED`)**
    - Missing `k.mw(w)` check (unlike A20, A-VSCHIST-3, A15), causing unwritten registers in `VSC_UNAPPLIED` on E146/E147 to record `NOTE.ASSUMED` on every compose and flood the 512-slot `NOTE_RING`.
13. **`emu/src/dev/audio.mjs:147-176`, `emu/src/dev/lensssc.mjs:125-130`, `emu/src/dev/hdmi.mjs:161-170`**
    - Register/state mutation happens before validation completes, leaving `this.reg` or stats partially mutated when a write throws `BUS`.
14. **`emu/src/dev/camfe.mjs:236-246, 265-276` (`CamFe.write`)**
    - Writes to `SSG.mask` (`0x9B000014`) fall through to `write()` without calling `ssg_update()`, so pending IRQ 18 bits are not reflected immediately.
15. **`emu/src/dev/timer.mjs:72, 82` (`romdWrite`) & `emu/src/dev/gio.mjs:38-47` (`GioKeyPins`)**
    - `Timer.romdWrite` passes negative `a - TIMER_BASE` into `ERR_RING`; `GioKeyPins` registers regions/IRQs per pin without merging shared GIO groups (safe for E143's current 8 pins, latent if two pins share a group).

### Firmware & Ports (`emu/src/fw/`)
16. **`emu/src/fw/expand.mjs:11, 38-56` (`expand`, `relocate`)**
    - `MAGIC` only checks 11 bytes (`'olycompress'`) and advances by `p + 1` rather than skipping past the decoded container; `relocate` lacks `to >= base` and `from + len <= img.length` bounds checks.
17. **`emu/src/fw/olyfw.mjs:24-42` (`descramble`)**
    - The unaligned fallback corrupts data if called in-place (`out === src`), unlike the aligned fast path.
18. **`emu/src/fw/xmap.mjs:55-60` (`windowHash`) & `emu/src/fw/facts.mjs:36-43, 68, 81-86`**
    - `windowHash` does not check `o + t.len[o] > t.n` for truncated trailing instructions; `callAt`, `loadAt`, `bytesAt` lack upper-bound checks against `img.length`.
19. **`emu/src/fw/updater.mjs:28-34` (`ask`)**
    - Does not check `r.ok` on the HTTP response before calling `r.text()`.

### HLE & Lab (`emu/src/lab/`)
20. **`emu/src/lab/text.mjs:163, 166, 273` (`GuiMixin.native_init`, `clear_layer`)**
    - Hardcodes `i < 6` / `i < 7` instead of `NRECORDS` / `NRECORDS + 1`, and hardcodes default `rect = [0, 0, 1664, 1200]` instead of `[0, 0, STRIDE, HEIGHT]`. Fails on bodies with 4 records/kind or smaller canvases.
21. **`emu/src/lab/play.mjs:1456-1461, 2159-2182` (`PlayLab.dispq`, `dispq_replies`)**
    - Cleared only in `PlaySession.end()`, not in `trim_lists()`; grows unboundedly during `--idle wall` (especially under `camapp 3` where VSC histogram cmd 16 runs every 50 ms).
22. **`emu/src/lab/a53isc.mjs:160-239, 301-357` (`A53Isc`)**
    - `this.slots[slot]` and `this.pool` handles leak when `fail()` throws; `SOCK.recv` misses a `this.mem` null check; `i32(r, 0x18)` allows negative lengths into `mem.read`.
23. **`emu/src/lab/jpeg.mjs:152-175` (`decodeJpeg`) & `emu/src/lab/resources.mjs:188` (`StringTable.raw`)**
    - `decodeJpeg` does not validate `len >= 2` (can infinite-loop on corrupt markers) or sub-element bounds; `StringTable.raw` lacks an `end + 1 < this.data.length` guard.
24. **`emu/src/lab/secready.mjs:231-235` (`secOrder`)**
    - A crossing reached on a gated path first and later on an ungated path is double-counted (`out.gated + out.ungated.length > out.crossings`).
25. **`emu/src/lab/sim.mjs:280-286` (`Simulator.write`), `emu/src/lab/osd.mjs:224-231` (`alloc`), `emu/src/lab/cpu2.mjs:316-319` (`osd_route`), `emu/src/lab/power.mjs:177`, `emu/src/lab/rawframe.mjs:143-150`, `emu/src/lab/strict.mjs:158`, `emu/src/lab/patchaudit.mjs:116`, `emu/src/lab/camapp.mjs:1543-1544`**
    - Minor edge cases: `Simulator.write` doesn't wrap `RspError` as `RuntimeError`; `OsdLab.alloc` silently wraps and overwrites earlier allocations; `cpu2.osd_route` reads `req + 4..` when `req === 0`; `power.mjs` wraps all JS errors as `PowerError`; `rawframe.mjs` throws plain `Error`; `.sort` comparators return `1` on equality.

## 2. Inconsistencies

2. **`emu/src/fw/place.mjs:14` (`inDram`) vs `emu/src/fw/board.mjs:167-171, 275`**
   - `place.mjs` hardcodes 384 MiB DRAM (`0x60000000..0x78000000` / `0xa0000000..0xb8000000`), while `board.mjs` uses 512 MiB on E143/E146/E147/E129/E130/E132/E133.

   - Hex/byte helpers (`hex8`, `h8`, `u32`, `u16`, `pack32`, `cat`) are redefined across dozens of files in `src/core/`, `src/dev/`, `src/lab/`, and `src/util/` (with `dev/bus.mjs` and `dev/engine.mjs` omitting `'0x'` in `hex8`).
   - `ERRORS` array duplicated in `src/lab/osdfmt.mjs:9-11` and `src/lab/osd.mjs:48-50`.
   - `PLAY_SCRIPT` / `playWorkload` duplicated in `bin/playperf.mjs` and `web/runner.mjs`.
   - Chrome DevTools launch/WebSocket harness duplicated in `bin/webgate.mjs` and `bin/sitegate.mjs`.
   - `usedLength` (`fw/xmap.mjs`, `fw/place.mjs`), `isHead` (`fw/identify.mjs`, `fw/respatch.mjs`), `plural` (`fw/patch.mjs`, `fw/respatch.mjs`).
4. **Device & Lab conventions**
   - `dev/vsccompose2.mjs:254` does not check `word >>> 29` for `E.PAL_FIELD` (unlike `vsccompose.mjs:322`); `dev/scpu.mjs:148` allows some `dbg === true` writes; `dev/intc.mjs:184-195` clears `TEST_ONCE` only on bank 0, not bank `b2`.

   - `host/firmware.mjs:86` writes files in-place (`writeFileSync`) whereas `host/nvram.mjs` and `host/card.mjs` write atomically via `.tmp` + `renameSync`.
   - `bin/xwhere.mjs:14` vs `bin/xto.mjs:16` differ on whether preload rows are in-range; neither validates unknown models.
   - CLI usage comments omit `--boot` (`bin/scpu.mjs`), `webkit-storage` (`bin/browsergate.mjs`), `--other-bin` (`bin/webgate.mjs`), and `setting:` (`host/session.mjs:693`).
   - `fw/facts.mjs:44-45, 65-67` has orphaned doc comments left behind when `valueAt`/`cached`/`alias` moved to `facts-const.mjs`.
   - `refs/display.mjs:56` & `checks/check_display.mjs:84` error strings cite `om1-vsc.c` instead of `om1-vsc-tables.c`.

## 3. Inefficiencies

1. **`emu/src/lab/camapp.mjs:1997-2003, 2189` (`boot_objects`)**
   - Under `camapp 3`, every status publish reads 2 MiB of guest HLS heap and scans 524,288 words, even though the result is monotonic and can be cached once true.
2. **`emu/web/ui.mjs:696-699` (`createPlayerUI`)**
   - Runs an eternal `setInterval(..., 1000)` to refresh `[data-si]` cells (never cleared on stop), when `showStatus(s)` already receives `s.stand_ins`.
3. **`emu/refs/fat.mjs:85-89, 204, 215` (`FatVolume.freeClusters`, `check`)**
   - Calls `this.next(c)` per cluster (~500,000 single-sector reads on an 8 GiB FAT32 card) instead of scanning FAT sectors sequentially.
4. **Hot-path allocations**
   - `emu/src/core/m4/cpu.mjs:701, 387, 844`: `new Int32Array(16)` / `[]` per `LDM`/`POP`/`VLDM`/`exceptionReturn`.
   - `emu/src/dev/bus.mjs:82, 89`: `new Uint8Array(4)` per live-view window read/write.
   - `emu/src/lab/jpeg.mjs:61-69`: `rows[...].subarray(...)` on every pixel during JPEG encode.
   - `emu/src/lab/scene.mjs:225, 334`: nested per-pixel `[[r,g,b], a]` arrays in `renderFrame`; redundant `exposureOf(scene)` inside `lensInUse` loop.
   - `emu/src/lab/play.mjs:996`: `[...this.heap_free.values()].some(...)` linear scan on `free(NULL)` / pre-play frees.
   - `emu/src/lab/player.mjs:973` & `play.mjs:3108`: `JSON.stringify` of full scene graph every 50 ms idle slice and frame compose.
   - `emu/src/util/parse.mjs:26`: `new RegExp(...)` compiled on every `decimalNumber()` call.
5. **Redundant guest reads & host work**
   - `emu/src/lab/storage.mjs:244`, `media.mjs:136,161,274`, `camapp.mjs:1789`: `sim.read(addr, 2)[0] | (sim.read(addr + 1, 1)[0] << 8)` reads the same address twice.
   - `emu/src/lab/rtos.mjs:92-93`, `text.mjs:131-132`, `menu.mjs:1304-1305`: re-reads `r.mdr - 1` which was already read in `call[6]`.
   - `emu/src/dev/engine.mjs:235-254`: reads destination rows twice when `KEY_MODE === 1`.
   - `emu/src/dev/ems1.mjs:130`: builds ~400-key `params()` object even when `this.source === null`.
   - `emu/src/dev/imgpipe.mjs:215`: `Object.values(J).includes(off)` per codec register write.
   - `emu/src/dev/pdt.mjs:80-103`: `Object.entries(ENGINES)` called twice per register access.
   - `emu/src/dev/intc.mjs:107-123`: scans all 356 IRQs × 7 levels (+ second core) on every line toggle.
   - `emu/src/fw/facts.mjs:75, 6558-6560`: `new TextEncoder()` per `findString()` call; `readPlacedFacts()` calls `touchDriver(img)` twice in a row.
   - `emu/fwmap/static.mjs:298-302`: O(M × F) linear `.filter()` over already-sorted `entriesSorted`.
   - `emu/fwmap/cover.mjs:24, 55`: leaks child stdout/stderr FDs in parent; allocates 32 MiB `Uint8Array` per group in `union()`.
   - `emu/bin/pubaudit.mjs:528-533, 613-624`: decodes every text blob twice and re-encodes UTF-8 in `charAt()`.
   - `emu/checks/lib/png.mjs:62`: `Uint32Array.from(words)` copies even when `words` is already a `Uint32Array`.
   - `tools/m4-oracle/objcheck.mjs:39-46`: spawns one `objdump` per run despite comment saying batched per 400 runs; `tools/mn10300dis.sh:10`: `dd bs=1`; `tools/a53-oracle/iscpeer.mjs:149-156`: 1-byte `fs.readSync`/`writeSync` loops.
